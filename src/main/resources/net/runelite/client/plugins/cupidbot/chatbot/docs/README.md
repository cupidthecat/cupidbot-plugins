# Chatbot

AI-powered in-game chatbot for CupidBot Hub using OpenAI Chat Completions.

## Features

- Sends configured chat context to OpenAI and generates short OSRS-style replies.
- Supports public, clan, and friends-chat listening options.
- Uses delay, length, cooldown, and filtering settings to control responses.

## Setup

1. Create an OpenAI API key.
2. Open the Chatbot plugin settings.
3. Paste the key into **OpenAI Settings**.
4. Configure model, trigger keyword, response delay, and chat sources.

Networking is plugin-owned and only runs when this local plugin is enabled and configured.
